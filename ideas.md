## Chosen: The Lab Notebook

### Design Movement
Clean scientific minimalism — inspired by laboratory notebooks and periodic tables, where information is organized, categorized, and presented with purpose.

### Core Principles
1. **Structured Information Architecture** — Each section is a labeled "experiment" with numbered headers
2. **Visual Categorization** — Color-coded skill tiles and tech tags create instant understanding
3. **Evidence-Based Presentation** — Stats and metrics prove capability rather than claiming it
4. **Clean Negative Space** — Generous whitespace lets content breathe

### Color Philosophy
- Background: Near-white with subtle gradient (warm off-white to very light teal)
- Primary accent: Teal (#2d9f8a) — represents precision and growth
- Secondary: Deep charcoal for text (#1a1a2e)
- Tertiary: Soft pink/rose for contrast accents (#e8726a)
- Cards: White with subtle borders and shadows

### Layout Paradigm
- Full-width sections with generous padding
- Two-column layouts where appropriate (content + sidebar info)
- Grid-based skill tiles (periodic table style)
- Two-column project cards (2x2 grid)
- Timeline for experience section

### Signature Elements
1. **Section numbering** — "01 — The Builder", "02 — The Tech Stack" etc.
2. **Periodic-table skill tiles** — 2-letter codes with full names, color-coded by category
3. **Phone mockup cards** — Project cards styled like phone screens with metrics

### Interaction Philosophy
- Hover reveals on skill tiles (tooltip with full description)
- Smooth scroll between sections
- Subtle card lift on hover
- Clean transitions, no excessive animation

### Animation
- Section entrance: fade-in + slight upward slide (200ms)
- Skill tile hover: scale(1.05) + shadow
- Card hover: translateY(-4px) + shadow increase
- Stats counter: count-up animation on scroll
- Staggered entrance for grid items (30ms delay each)

### Typography System
- Display font: **Outfit** (bold, geometric, modern) — for headings and large text
- Body font: **DM Sans** (clean, readable) — for descriptions and body text
- Mono font: **JetBrains Mono** — for code snippets and tech tags
- Hierarchy: Section labels (uppercase, tracking-widest, teal), Headings (bold, large), Body (regular, readable)

### Brand Essence
"Code that compiles. Apps that deploy." — A B.Tech IT student building real-world Android and Java solutions. Different because of structured, evidence-based presentation of skills.

### Personality Adjectives
Precise · Ambitious · Systematic

### Brand Voice
Confident, technical, slightly playful. Never generic.
- Headline example: "From class to production-grade code"
- CTA example: "See what I've built"

### Wordmark & Logo
A stylized beaker/flask icon (⚗) combined with initials "DK" — clean geometric lines, teal color

### Signature Brand Color
Teal (#2d9f8a) — used for accents, badges, active states, and the logo
