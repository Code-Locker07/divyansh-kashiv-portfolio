# Design Ideas — Divyansh Kashiv Mobile Dev Portfolio

## Chosen: Dark Glassmorphic Theme

### Design Movement
Dark glassmorphism — frosted glass panels on near-black background with single accent color (electric teal), subtle glow effects, and smooth scroll-reveal animations.

### Core Principles
1. **Dark Base with Glass Overlays** — Near-black (#07080d) background with semi-transparent glass panels
2. **Single Accent Color** — Electric teal used consistently for highlights, glows, and CTAs
3. **Smooth Micro-interactions** — Hover lifts, glow effects, animated counters on scroll
4. **On-Scroll Reveal** — IntersectionObserver-based fade/slide-in for each section

### Color Philosophy
- Background: #07080d (near-black)
- Glass panels: rgba(255,255,255,0.05) with backdrop-filter: blur(16px)
- Borders: rgba(255,255,255,0.1)
- Accent: Electric teal/cyan (#00d4aa)
- Text: White/near-white for readability

### Typography
- Display: Outfit (bold headings)
- Body: DM Sans
- Mono: JetBrains Mono (section labels, stats)

### Signature Elements
1. Glass cards with blur backdrop and subtle borders
2. Animated number counters that count up on scroll
3. Glow effects on hover (border brightens, slight lift)
4. Section numbering "01 — About" in mono font
5. Sticky glass navbar

### Brand Voice
"Building backend systems with Java & Spring Boot, one project at a time"
CTA: "View my experiments" / "Download my blueprint"
